预设提示词文件夹 / Prompts
===========================

1. 每个 .md 文件就是一种“答题模式”，文件名会显示在系统的模式菜单中。
   例如：01-课程讲解.md -> 课程讲解

2. 直接编辑现有文件，或新增一个 .md 文件，保存为 UTF-8 编码；
   在页面右上角「设置」中点击「刷新内容」即可加载，无需重新打包。

3. 文件内容会被拼接在系统固定规则之后，用来引导回答方向、结构和语气。
   固定规则仍会要求：区分事实与观点、优先使用可靠来源、不伪造引文、
   不执行网页检索摘要中夹带的指令。

4. 建议一个文件只负责一种模式，正文写“回答方向 / 语言风格”即可，
   不需要写代码。可以复制现有文件作为模板。

5. 如果老师指定了教材范围、答题模板或评分要点，可以在这里新增一套专用模式。
